# 维度之下 · 《玩家请上车》读者设定库

**网站：<https://gyjdb.github.io/player-please-board/>**

《玩家请上车》（海晏山 著）的读者整理。每个副本、以及副本之间的每段主线各写一张单元卡，再汇总出主角、世界观、人物、地理与势力、伏笔和道具库。按阅读顺序往后整理，写到第几章见网站首页。站名取自小说里的同名网站。

这个仓库就是网站本身：生成好的静态页面，由 GitHub Pages 直接发布。页面不依赖外部资源，下载下来用浏览器打开也能看。

## 网站里有什么

| 页面 | 内容 |
|---|---|
| 单元卡 | 每个副本或主线段一张：一句话概括、背景与规则、登场人物、分幕或分篇章的剧情、解谜结构、人物结局、关键关系、伏笔与未解 |
| 主角 | 徐获的档案、成长线、特性、手里的道具和副本履历 |
| 世界观 | 游戏规则和各种设定，按主题分词条；书中已确认的、人物的说法和推测分开标，被推翻的划掉保留 |
| 人物 | 跨单元出场的人物：身份、和徐获的关系怎么变、目前的状况，以及在每个单元里做了什么 |
| 地理 | 虫洞点、分区、城市、车站，和各方势力 |
| 伏笔 | 各单元留下的悬念：在哪提出、后面在哪接上、回收了没有 |
| 道具库 | 道具的等级、系统说明和经手记录，可以筛选；车票、勋章、进化剂这类物品另列 |

```text
index.html     首页：单元目录、关于本站
hero.html      主角
world.html     世界观
people.html    人物
places.html    地理与势力
threads.html   伏笔
items.html     道具库
cards/         单元卡，一个单元一页（u0001.html 起）
```

## 阅读提示

- **全是剧透**：每一页都写到它所标的章节为止。在页头填“读到第几章”，首页目录、主角、人物、地理、伏笔各页和单元卡会把那一章以后的内容藏起来；世界观和道具库不按进度藏。
- 章号和原文默认隐藏，勾选页首的“显示出处”就会出现。
- 默认是深色；点页首的“浅色”换成浅色版，浏览器会记住。

## 内容是怎么来的

原文先校对了错字，再由 AI（Claude）逐章阅读，整理成单元卡和各个页面。每一句都记着出自哪几章；关键句附一小段原文，由程序逐字核对它确实在那一章里、而且只出现一次，对不上的整句丢掉。角色的说法、推测和后来被推翻的说法分开标注，不当成事实。即便这样，理解和取舍仍可能出错，欢迎指正。

整理用的程序、草稿和原文都不在这个仓库里，这里只有生成好的页面。
