# 维度之下 · 《玩家请上车》读者设定库

**网站：<https://gyjdb.github.io/player-please-board/>**

《玩家请上车》（海晏山 著）的读者整理。每个副本、以及副本之间的每段主线各写一张单元卡，再汇总出主角、世界观、人物、地理与势力、伏笔、道具库和专题。按阅读顺序往后整理，写到第几章见网站首页。站名取自小说里的同名网站。

这个仓库就是网站本身：生成好的静态页面，由 GitHub Pages 直接发布。页面不依赖外部资源，下载下来用浏览器打开也能看。

## 网站里有什么

| 页面 | 内容 |
|---|---|
| 单元卡 | 每个副本或主线段一张：卡头一句导语，背景与规则、登场人物、剧情梗概、解谜、徐获的收获、伏笔与未解 |
| 主角 | 徐获的档案、成长线（等级、进化率、副本评级）、特性（运行图和每项特性的升级路线）、手里的道具和副本履历 |
| 专题 | 《三向超级进化》：精神、空间、时间三个方向各一篇长文，讲清概念、他怎么学会、还做不到什么 |
| 世界观 | 游戏规则和各种设定，按主题分组；书中已确认的、人物的说法和推测分开标 |
| 人物 | 反复出场的人物各一篇小传（身份、和徐获的关系、现状），只在一两个单元出现的人列在“各地相识” |
| 地理 | 虫洞点、分区、城市、车站和各方势力，每处一段概述，重要的附大事记 |
| 伏笔 | 跨单元的核心悬念和人物、势力线：怎么埋下、后来揭开了多少，未解的放在前面 |
| 道具库 | 道具的等级、类别、系统说明、来历与去向，可以搜索和筛选；超级道具在页首单列；车票、勋章、进化剂这类物品另列 |

index.html       首页：单元目录、关于本站

## 阅读提示

- **全是剧透**：每一页都写到它所标的章节为止。在页头填“读到第几章”，首页目录、主角、人物、伏笔各页和单元卡会把那一章以后的内容藏起来；世界观、地理与势力、道具库和专题写全书，不按进度藏（页首有提醒）。
- 章号和原文默认隐藏，勾选页首的“显示出处”就会出现。
- 默认是深色；点页首的“浅色”换成浅色版，浏览器会记住。
- 长页有“本页”跳转；手机上目录在右下角的按钮里。

## 内容是怎么来的

原文先校对了错字（两个模型各出一份错字清单，逐条审过再改），再由 AI（Claude）逐章阅读，整理成单元卡和各个页面；GPT 参与了校对和审阅。每一句都记着出自哪几章；关键句附一小段原文，由程序逐字核对它确实在那一章里、而且只出现一次，对不上的整句丢掉。角色的说法、推测和后来被否定的说法分开标注，不当成事实。即便这样，理解和取舍仍可能出错，欢迎指正。

整理用的程序、草稿和原文都不在这个仓库里，这里只有生成好的页面。
